# Publishing options

Choose the smallest format that helps the intended traveller decide. These are workflow choices, not separate guarantees of commission.

| Asset                   | Useful example                                            | Capability to discover                                                                       |
| ----------------------- | --------------------------------------------------------- | -------------------------------------------------------------------------------------------- |
| Hotel link              | One Bangkok hotel recommendation                          | Studio Embeds: `transactional_url_create`                                                    |
| Room or rate-plan link  | A family room with a particular meal or cancellation plan | Studio Embeds: `transactional_url_room_types`, then create the focused link                  |
| Curated collection      | A handpicked Bangkok shortlist                            | Studio Curation: transactional lists with `CURATED` source and item management               |
| Saved search            | Family-friendly hotels in a destination                   | Studio Curation: transactional lists with `SEARCH` source and supported live filter criteria |
| Ranked collection       | A destination's ranked hotel selection                    | Studio Curation: transactional lists with `RANKED` source and a real destination lookup      |
| Bookable cards or grids | Recommendations inside a travel guide                     | Studio Embeds and the current web-component integration                                      |
| Interactive map         | Hotels around an itinerary's locations                    | Studio Embeds: map tools, when exposed by the connected server                               |
| WinkLinks storefront    | One public home for hotel links, collections and maps     | Link Manager: syndicated items, categories and settings                                      |

Consult live tools before composing requests. Toolsets and deployments can differ; a documented feature is not proof that its creation tool is connected. Lists, maps and other assets may need a WinkLinks entry or an embedded page to become shareable; do not invent a standalone short URL.

Social previews and QR codes distribute an existing link. WinkLinks can also host existing external affiliate URLs; shortening or displaying one does not enroll the user in that program.

Add Analytics when optimizing conversions and Payment when the user asks to inspect or withdraw earnings. Direct supplier relationships through Distribution can provide different terms; verify the actual agreement before promising a commission.

See [WinkLinks publishing formats](https://wink.travel/portal/link-manager/wink-links/), [shareable links](https://wink.travel/studio/shareable-links/) and the [MCP toolset guide](https://wink.travel/developers/mcp/) for current product guidance.
